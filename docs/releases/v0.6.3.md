Windows 10 / 11（x64）请下载 **`WallNote-Setup-0.6.3-x64.exe`**。如正在使用旧版，请先在系统托盘退出 WallNote，再运行安装向导；同一用户的日程、便签和手机配对会继续沿用。

### 修复：内屏高缩放下鼠标选择错位

从 HDMI 大屏切回使用 150% 缩放的内屏时，鼠标可能指着一个日期却选中别处，或明明在组件内却点不到。现在桌面组件在处理指针时会使用同一套物理坐标来判断命中位置，不需要更改 Windows 显示缩放或重置组件布局。

### 修复：图钉模式白色边角

置顶窗口按屏幕缩放裁切到卡片的圆角，移除多余描边。拖动调整大小时同步更新轮廓；取消置顶后恢复桌面壁纸合成。

本版包含 Windows 安装与系统卸载、组件图钉动效，以及可查看连接状态的「手机同步」入口。发行附件为安装程序和对应的 SHA-256 校验文件。
