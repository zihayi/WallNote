## 安装

Windows 10 / 11（x64）请下载 **`WallNote-Setup-0.6.2-x64.exe`**。运行安装向导后即可从开始菜单或桌面快捷方式启动。安装包内置手机同步接收服务，无需另装 Node.js 或 Python。

## 变化

- 新增 Windows 安装、覆盖升级与系统卸载支持。「偏好设置」可开启登录时启动。
- 优化管理面板打开、关闭和桌面组件的图钉反馈；取消置顶可回到桌面网格，并遵从系统减少动态效果设置。
- 桌面日历和管理面板都能查看手机连接状态、进入配对或刷新。日历来源统一显示为「手机同步」。

## 从旧版迁移

先从系统托盘退出旧版，再用同一 Windows 用户安装。程序复用原有数据目录；普通卸载会保留个人日程、便签和配对设置。

发行附件为 Windows 安装程序及其 SHA-256 校验文件。
