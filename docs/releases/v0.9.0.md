Windows x64 安装包：**`WallNote-Setup-0.9.0-x64.exe`**。

- **文件抽屉**：在「工作台 → 整理布局」勾选后应用，桌面项目会按应用、文档、文件夹、其他自动归类。支持打开、在资源管理器中定位与自动刷新，原文件保留在原目录。
- **可选隐藏图标**：在抽屉底部单独开启。收起抽屉或退出 WallNote 时恢复本次隐藏，保留用户原有的隐藏状态。
- **桌面社区日报**：顶部小区域显示本期 AI 小结，卡片内切换社区标签和「新 PR / 待认领 Issue / 已合并」。悬停或键盘聚焦条目时展示对应的 AI 摘要。
- **一次生成，离线查看**：总览与逐条摘要一起缓存，悬停不会重复请求 DeepSeek。可选参考公开说明的短摘录。旧日报可正常阅读，重新生成后获得新版摘要。
