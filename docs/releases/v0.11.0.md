Windows x64 安装包：**`WallNote-Setup-0.11.0-x64.exe`**。更新前请从托盘退出旧版。

- 多屏时，在工作台「切换屏幕」选择笔记本内屏或外接显示器，整组桌面组件立即移过去。也可以在托盘右键选择「切换组件屏幕」。
- 切换后保留自定义布局、置顶和收起状态。外屏断开时组件暂回主屏，重新连接后自动返回。
- 「整理布局」里单独移动一个模块到另一块屏幕时，也会保留它在工作区中的相对位置。
- 启动时日历默认选中当天，时间安排同步跳转。
- 便签支持按全部标题切换、直接新建删除、预设色和自定义背景色，以及插入、粘贴、复制图片；图片随便签及备份保存。
- 置顶模块的位置和尺寸单独记忆，浮动时拖动、缩放不会改变桌面布局；取消置顶恢复原位置。
