Windows x64 安装包：**`WallNote-Setup-0.10.1-x64.exe`**。更新前请先从系统托盘退出旧版。

- 模块内的左右键由模块处理，空白处右键不会打开 Windows 桌面菜单；模块外仍可照常操作桌面。
- 文件抽屉右键立即显示常用操作，并为当前文件准备完整的 Windows 菜单。菜单进程空闲 15 秒后退出。本机连续打开系统菜单的中位耗时从 884 ms 降至 209 ms；首次打开仍取决于系统扩展的加载速度。
- 简化工作台、设置和社区日报的界面。桌面模块按需加载，编辑便签或待办时减少了无关窗口的刷新。
- 新增岬角灯塔、雪线、竹间月、秋日梯田、套色习作和潮汐线，内置壁纸共 12 张。
