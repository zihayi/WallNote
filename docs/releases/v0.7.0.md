## 社区日报与桌面模块布局

Windows x64 请下载 **`WallNote-Setup-0.7.0-x64.exe`**。更新时从托盘退出旧版，再运行安装程序。

- 新增「社区日报」，预设 LLVM 和 MLIR，也可指定其他公开 GitHub 仓库和标签。分别查看新 PR、已合并 PR 和当前可认领的贡献 Issue，打开原文或加入本地待办。
- 在「订阅设置」配置自己的 DeepSeek API Key、模型及关注方向，可生成逐条附来源的中文导读。密钥由 Windows 加密保存，模型仅接收关注方向和公开条目元数据。
- 可设定本地时间每日生成；WallNote 在托盘运行即可，当天启动或唤醒后可补跑。保留最近 7 天的日报。手动生成和 GitHub 原始动态不要求配置 AI。
- 在「社区日报」或「偏好设置」选择左栏、中栏、右上、右下的卡片；支持交换位置、留空和恢复后沿用布局。
